如何获取 GitHub 访问令牌

1. 到 GitHub 创建 Fine-grained token ↗

2. 仓库访问选择 Only select repositories，仅选 personal-notes-data；在 Repository permissions 中，将 Contents 设为 Read and write。

3. 复制令牌，粘贴到下方。令牌只填在这个网页里，请勿发到聊天或分享给他人。

笔记仓库：zeranhub/personal-notes-data，需保持私有。

PIN 只在此设备使用，主要防止别人随手打开，不适合保护特别敏感的资料。换设备时，需要再次输入 GitHub 令牌并设置该设备的 PIN。
